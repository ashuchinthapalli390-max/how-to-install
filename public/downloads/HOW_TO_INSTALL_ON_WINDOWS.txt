1. WINDOWS OPTIONS OVERVIEW
================================================================================
There are two great ways to run ChatXa on a Windows computer:

OPTION A (NATIVE WINDOWS APP):
- ChatXa is compiled into a native 64-bit Windows binary (`chatxa.exe`).
- Runs directly on your PC hardware with smooth animations, high framerates, 
  and direct access to your Windows desktop notifications, webcam, and audio.

OPTION B (ANDROID APK VIA EMULATOR):
- You already have `ChatXa-Android-Release.apk` (549.7 MB).
- Simply drag and drop the APK into a free Android emulator like BlueStacks 5, 
  LDPlayer, or NoxPlayer. It installs in 10 seconds and works right away!

2. METHOD 1: NATIVE WINDOWS DESKTOP APP (STANDALONE EXE)
================================================================================
ChatXa has built-in Flutter Windows desktop support configured in the repository.

HOW TO COMPILE & RUN THE NATIVE WINDOWS APP:
1. Open PowerShell or Command Prompt in the ChatXa project folder:
   cd "c:\Users\ashuc\OneDrive\Desktop\ChatXa"
2. Run the release build command:
   flutter build windows --release
3. Flutter will compile the C++ runner and generate the production files at:
   c:\Users\ashuc\OneDrive\Desktop\ChatXa\build\windows\x64\runner\Release\
4. Inside that folder, you will find:
   - `chatxa.exe` (The main application executable)
   - `flutter_windows.dll` (Flutter engine)
   - `data\` folder (Contains app assets, icons, fonts, and Supabase config)
5. Double-click `chatxa.exe` to run ChatXa as a native desktop application!

HOW TO DISTRIBUTE TO OTHER WINDOWS COMPUTERS:
- Zip the entire `Release` folder (or create a desktop shortcut to `chatxa.exe`).
- When sending to another PC, send the ENTIRE folder (the `.exe` requires 
  `flutter_windows.dll` and the `data/` folder in the same directory to run).

================================================================================
If you want to test the mobile app experience on your PC without compiling:

1. Download a free Android emulator on your PC:

2. Install and launch the emulator.
3. Open File Explorer on Windows and locate your APK:
   c:\Users\ashuc\OneDrive\Desktop\ChatXa\app_store\ChatXa-Android-Release.apk
4. Drag and drop the `ChatXa-Android-Release.apk` file directly into the emulator window!
   (Or click the "Install APK" button on the emulator's right-side toolbar).

6. Click the ChatXa app icon inside the emulator to open it.
7. Webcams, microphones, keyboard typing, and mouse gestures work automatically!

4. METHOD 3: RUN VIA WINDOWS SUBSYSTEM FOR ANDROID (WSA ON WINDOWS 11)
================================================================================
If your Windows 11 PC has Windows Subsystem for Android (WSA) installed, 
ChatXa can run like an official Windows store app in its own window!

STEP-BY-STEP:
1. Open "Windows Subsystem for Android Settings" on your Windows 11 PC.
2. In the "Developer" tab, turn ON "Developer mode".
3. Note the IP address and port shown (e.g., `127.0.0.1:58526`).
4. Open PowerShell on Windows and connect ADB:
   adb connect 127.0.0.1:58526
5. Install the ChatXa APK:
   adb install "c:\Users\ashuc\OneDrive\Desktop\ChatXa\app_store\ChatXa-Android-Release.apk"
6. Once it says "Success", open your Windows Start Menu:
   ChatXa will appear right in your Start Menu as a native Windows application!

5. HOW TO BYPASS WINDOWS DEFENDER SMARTSCREEN
================================================================================
When running a newly compiled `chatxa.exe` on Windows for the first time, 
Windows Defender SmartScreen may display a blue popup:

  "Windows protected your PC"
  "Microsoft Defender SmartScreen prevented an unrecognized app from starting."

HOW TO RUN IT:
1. Click the small text link that says: "More info".
2. A new button will appear at the bottom: "Run anyway".
3. Click "Run anyway".
4. ChatXa will launch immediately and Windows will remember your choice!

6. REQUIRED PREREQUISITES FOR WINDOWS
================================================================================
To ensure smooth operation of native Windows apps:

1. MICROSOFT VISUAL C++ REDISTRIBUTABLE (x64):
   - If you get an error mentioning `MSVCP140.dll` or `VCRUNTIME140.dll`, install:
     https://aka.ms/vs/17/release/vc_redist.x64.exe
   - (Included on almost all Windows PCs with gaming or developer tools).

2. GRAPHICS DRIVERS:
   - Make sure your Intel, NVIDIA, or AMD graphics drivers are up to date 
     for hardware-accelerated rendering and video playback.

7. ENABLING WEBCAM & MICROPHONE PERMISSIONS IN WINDOWS
================================================================================
For LiveKit voice and video calls on Windows:
1. Open Windows "Settings" (Windows Key + I).
2. Go to "Privacy & Security" (or "Privacy" in Windows 10).
3. Under "App permissions":
   - Click "Camera" -> Ensure "Camera access" is ON and "Let desktop apps access your camera" is ON.
   - Click "Microphone" -> Ensure "Microphone access" is ON and "Let desktop apps access your microphone" is ON.

8. TROUBLESHOOTING & FAQS
================================================================================

Q1: "The code execution cannot proceed because flutter_windows.dll was not found"?
A1: You moved `chatxa.exe` out of its folder. 
    Fix: Keep `chatxa.exe`, `flutter_windows.dll`, and the `data` folder together 
    in the same folder. If you want a desktop icon, right-click `chatxa.exe` -> 
    "Send to" -> "Desktop (create shortcut)".

Q2: Can I resize the ChatXa window or go fullscreen on Windows?
A2: Yes! The window can be resized freely, maximized, or snapped to sides using 
    standard Windows Snap (Windows Key + Arrow Keys).

Q3: Does Supabase authentication and realtime chat sync between phone and Windows?
A3: Yes! The same backend database (`zewkgbycyxuotfwoicdr`) powers both platforms. 
    Any message or friend request sent on your phone appears instantly on your PC.
