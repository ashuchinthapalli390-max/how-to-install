1. macOS OPTIONS OVERVIEW
================================================================================
Depending on your Mac model, you have two powerful ways to install ChatXa:

OPTION A (APPLE SILICON MACS — M1, M2, M3, M4 CHIPS):
- Because Apple Silicon Macs share the exact same ARM64 architecture as iPhones, 
  you can run the iOS file `ChatXa-iOS-Release.ipa` DIRECTLY on your Mac!
- Runs in a clean, resizable window with full keyboard shortcuts, trackpad gestures, 
  and FaceTime HD webcam support.

OPTION B (NATIVE macOS APP FOR ALL MACS):
- Compiled using Flutter's native macOS engine (`chatxa.app`).
- Runs natively on both Intel and Apple Silicon Macs.


================================================================================
2. METHOD 1: RUN iOS IPA DIRECTLY ON APPLE SILICON MAC (M1/M2/M3/M4)
================================================================================
If your Mac has an M1, M2, M3, or M4 chip (MacBook Air, MacBook Pro, Mac mini, iMac, Mac Studio):

TECHNIQUE 1: USING SIDELOADLY FOR MAC (RECOMMENDED)
1. Download Sideloadly for macOS from: https://sideloadly.io
2. Open Sideloadly on your Mac.
3. Under the "Target Device" dropdown, select: "This Mac".
4. Drag and drop "ChatXa-iOS-Release.ipa" into the Sideloadly window.
5. Enter your personal Apple ID email.
6. Click "Start". Enter your Apple ID password if prompted.
7. Sideloadly will automatically sign and install ChatXa directly into your 
   Mac's `/Applications/` folder!
8. Open your Mac "Launchpad" or "Applications" folder and click ChatXa to launch!

TECHNIQUE 2: USING PLAYCOVER FOR MAC
1. Download PlayCover from: https://playcover.io
2. Drag PlayCover to your `/Applications` folder and open it.
3. Drag and drop "ChatXa-iOS-Release.ipa" into the PlayCover window.
4. PlayCover will install ChatXa with full mouse mapping and window scaling.
5. Double-click ChatXa to enjoy!


================================================================================
3. METHOD 2: NATIVE macOS DESKTOP APP (.APP / .DMG)
================================================================================
The ChatXa repository contains a complete native macOS platform target in `macos/`.

HOW TO COMPILE ON A MAC:
1. Transfer or clone the `ChatXa` repository onto your Mac.
2. Open Terminal and navigate to the project directory:
   cd path/to/ChatXa
3. Run the macOS release compilation command:
   flutter build macos --release
4. Flutter will compile the native Cocoa app and bundle it at:
   build/macos/Build/Products/Release/chatxa.app
5. Drag `chatxa.app` into your Mac's `/Applications` folder.
6. ChatXa is now permanently installed on your Mac!

4. CRITICAL: BYPASSING APPLE GATEKEEPER & QUARANTINE
================================================================================
When opening a newly sideloaded or custom-built app on macOS, Apple's Gatekeeper 
security may display one of these alerts:

  "ChatXa.app cannot be opened because Apple cannot check it for malicious software."
  OR
  "ChatXa.app is damaged and cannot be opened. You should move it to the Trash."

HOW TO BYPASS THIS IN 5 SECONDS:

SOLUTION A (FASTEST MOUSE CLICK METHOD):
1. Open Finder and go to your "Applications" folder.
2. Hold down the "Control" key on your keyboard and click on "ChatXa.app" (or Right-Click).
3. Select "Open" from the shortcut menu.
4. A dialog will appear with an "Open" button.
5. Click "Open"! macOS will permanently whitelist ChatXa.

SOLUTION B (MAC SYSTEM SETTINGS):
1. Open Mac "System Settings" (Apple Menu  -> System Settings).
2. Click "Privacy & Security" in the left sidebar.
3. Scroll down to the "Security" section.
4. You will see a message: "'ChatXa.app' was blocked from use because it is not from an identified developer."
5. Click the "Open Anyway" button next to it.
6. Enter your Mac administrator password or Touch ID to confirm.

SOLUTION C (TERMINAL COMMAND TO REMOVE QUARANTINE FLAG):
If macOS still says the file is "damaged" due to Apple quarantine:
1. Open the "Terminal" app (press Command + Space, type "Terminal").
2. Run this command:
   sudo xattr -rd com.apple.quarantine /Applications/chatxa.app
3. Enter your Mac login password when prompted.
4. Double-click `chatxa.app` in Applications — it will open smoothly!

5. SYSTEM PERMISSIONS (CAMERA, MIC & LOCATION ON MAC)
================================================================================
When you open ChatXa and start a LiveKit audio/video call or take a Snap:
1. macOS will show standard system permission popups:
   - "ChatXa would like to access the Camera" -> Click "OK".
   - "ChatXa would like to access the Microphone" -> Click "OK".
2. If you ever accidentally clicked "Don't Allow":
   - Go to System Settings -> Privacy & Security.
   - Check "Camera" and "Microphone" and ensure the toggle next to ChatXa is ON.
